SQL → XLSX 변환기

SQL 파일을 드래그&드롭하면, 원본 파일명으로 폴더를 만든 뒤 그 안에 각 테이블을 테이블명.xlsx 형태로 저장합니다.

SQL 파일을 여기에 드래그&드롭
또는 클릭해서 파일 선택 (.sql / .txt)
변환 시작 시 저장할 상위 폴더를 한 번 선택합니다.
예: backup.sql → 선택한 폴더/backup/users.xlsx, reservations.xlsx ...
파일은 외부 서버로 업로드하지 않고 브라우저 안에서만 처리합니다.
폴더 직접 저장 기능 때문에 Chrome 또는 Edge 사용을 권장합니다.
SQL 파일을 드래그&드롭하거나 선택해주세요.
